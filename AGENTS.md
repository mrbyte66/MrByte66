# AGENTS

## Purpose

This file provides the minimum project context for AI agents.

Before starting any development task, read the project documentation in the following order:

1. Vision.md
2. Project.md
3. Requirements.md
4. Architecture.md
5. Roadmap.md
6. Decisions.md
7. AI/AI-Guidelines.md

Read additional documents when the task requires them (e.g. Database-Design.md, Design-Principles.md, Local-Development-Setup.md).

## Working Rules

Before making changes:

- Understand the existing architecture.
- Follow documented technical decisions.
- Prefer consistency over introducing new patterns.
- Do not make major architectural decisions without updating the documentation.

## Documentation Rules

When a significant change is made:

- Update the relevant Markdown documents.
- Record long-term technical decisions in `Decisions.md`.
- Keep `Architecture.md` synchronized with architectural changes.

The Markdown documentation is the single source of truth for the project.
