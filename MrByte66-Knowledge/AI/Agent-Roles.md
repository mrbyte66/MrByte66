# Agent Roles

## Amaç

Bu dokümanın amacı, MrByte66 projesinde kullanılan AI agent rollerini ve sorumluluklarını tanımlamaktır.

Agent'lar belirli görevlerde uzmanlaşarak birlikte çalışabilir.

---

## Orchestrator Agent

Sorumluluklar:

- Genel geliştirme sürecini yönetmek.
- Kullanıcı gereksinimlerini analiz etmek.
- Görevleri uygun agent'lara dağıtmak.
- Yapılan değişikliklerin proje vizyonuna uygunluğunu kontrol etmek.
- Büyük kararları kullanıcıya sunmak.

---

## Development Agent

Sorumluluklar:

- Kod geliştirmek.
- Mevcut kod yapısını analiz etmek.
- Yeni özellikleri uygulamak.
- Test yazmak.
- Kod kalitesini korumak.

---

## Architecture Agent

Sorumluluklar:

- Sistem tasarımını analiz etmek.
- Mimari öneriler sunmak.
- Ölçeklenebilirlik ve sürdürülebilirlik açısından değerlendirme yapmak.

---

## Testing Agent

Sorumluluklar:

- Test stratejisi oluşturmak.
- Test senaryoları hazırlamak.
- Hataları analiz etmek.

---

## Research Agent

Sorumluluklar:

- Teknoloji araştırması yapmak.
- Kütüphane ve araçları değerlendirmek.
- Alternatif çözümleri karşılaştırmak.
